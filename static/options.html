Anti-Judol Shield — Pengaturan

Perlindungan

Platform

YouTube aktif bawaan. Platform lain perlu izin akses situs tersebut; Chrome akan meminta izin saat kamu mencentangnya, dan izin bisa dicabut kapan saja.

Semua situs (opsional)

Perlu izin "baca dan ubah data di semua situs". Pemeriksaan 100% lokal: isi halaman tidak pernah dikirim ke mana pun, termasuk ke AI. Juga menampilkan halaman peringatan (bukan layar error) saat membuka situs judi, dan memperingatkan halaman situs yang diretas untuk promosi judi.

Blokir situs judi

Daftar diunduh dari cdn.jsdelivr.net. Tidak ada data tentang kamu yang dikirim; pemblokiran dilakukan browser sendiri, ekstensi tidak melihat situs yang kamu buka.

Kata kunci sendiri

Dicocokkan setelah penyamaran dibongkar, jadi "gacor88" juga menangkap "g4c0r 88" dan "𝐆𝐀𝐂𝐎𝐑𝟖𝟖".

Area yang dipindai

Klasifikasi AI (opsional)

Tanpa langkah ini, ekstensi tetap bekerja 100% di perangkat dengan filter lokal dan tidak mengirim data apa pun.

Data yang dikirim jika diaktifkan: teks komentar/judul/chat YouTube yang tampil di layar dan nama pengirimnya, hanya ke api.typesafe.ai (dan openrouter.ai bila key fallback diisi), semata untuk menentukan apakah itu promosi judi. Tidak ada URL, riwayat, cookie, atau data akun yang dikirim. Kebijakan privasi

Key disimpan hanya di perangkat ini, tidak bisa dibaca halaman web maupun script konten, dan tidak pernah ditampilkan ulang. Kosongkan kolom untuk mempertahankan key yang tersimpan.

Data

Memakai Chrome Sync milikmu. API key tidak pernah ikut disinkronkan atau diekspor.
