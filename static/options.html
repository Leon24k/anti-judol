Tanpa langkah ini, ekstensi tetap bekerja 100% di perangkat dengan filter lokal dan tidak mengirim data apa pun.

Data yang dikirim jika diaktifkan: teks komentar/judul/chat YouTube yang tampil di layar dan nama pengirimnya, hanya ke api.typesafe.ai (dan openrouter.ai bila key fallback diisi), semata untuk menentukan apakah itu promosi judi. Key disimpan hanya di perangkat ini, tidak bisa dibaca halaman web maupun script konten, dan tidak pernah ditampilkan ulang. Kosongkan kolom untuk mempertahankan key yang tersimpan.
